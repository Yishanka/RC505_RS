# RC505 RS 0.4：FX 实现、延迟与验证边界

[BOSS 官方参数表 rev.04，第 34–43 页](https://static.roland.com/assets/media/pdf/RC-505mk2_Parameter_eng04_W.pdf#page=34) 是控制语义的第一参考；[完整家族列表](RC505_MK2_FX_CATALOG_CN.md) 列出覆盖情况与优先级。以下是 RC505 RS 的实际实现，不是 BOSS 源码或实机听感等效结论。

## 路由与共同约定

0.3 新增的 19 个音频效果家族均可放入 Input FX 或 Track FX，并可编辑、保存为预设、随工程和回放保存。0.4 继续完善这些家族、共振峰处理与算法延迟对齐。OSC 仍是独立音源；普通音频效果需要输入或轨道音频，没有无意义的钢琴卷帘或音符试听按钮。

新工程的 Input FX 默认按 **A → B → C → D** 串行处理。旧工程如果保存的是 Legacy 路由，仍使用旧分组次序：OSC／旧 MyDelay → Vocoder → Filter → Reverb → 新 Audio FX → Input Roll。Legacy 下新增效果不按所有槽位共同排序；可在 Session／工程设置主动改为 A → D。Track FX 按槽位排列，每条轨道独立启停。

同步的声像、颤音、切片和移调控制序列跟随共同采样时钟，不会因五条轨道长度不同、起点错开或循环回卷而分别重启。Track Filter 的原步进门控仍保留随轨循环的含义。

内部音频链和现代叠录使用有限的浮点余量（保护上限 ±16，即约 +24 dBFS）。中间效果不再一律硬截到 ±1；可以降低推子或通过主压缩收回电平。最终音频输出仍限制到 ±1，并记录削波。失真器、延迟反馈保护和其他算法本身的非线性仍保留。浮点 WAV 快照可以保存大于 1 的采样值；这属于 0.3 的声音变化。

## 新增效果与实际算法

| 类型 | 实际实现与主要控制 | 实际限制 |
|---|---|---|
| Transpose／移调 | 立体声相位声码器，按瞬时频率重映射频谱；−12～+12 半音；可画 1～16 步相对半音序列；可选共振峰保持／偏移 | 不改变循环时长；瞬态会变柔；不是 BOSS 的 Mode 1/2 |
| Electric／电音校音 | 有界、分散计算的 YIN 单声部检测，半音阶／大调／自然小调吸附，移调、校音速度和稳定度；可选共振峰保持／偏移 | 是人声阶梯校音，不是“所有电子音乐效果”的总称；不适合同时输入多个人声 |
| Harmonist／手动和声 | 指定主音与调式，按音阶求三、四、五、六度或八度和声；独立原声、和声电平及声像；可选共振峰保持／偏移 | 单声部检测；无 MIDI 自动和弦；不是 BOSS 共振峰算法的复刻 |
| Distortion／失真 | 0.4.1新增Vocal/Boost/OD/DS/Metal/Fuzz六套滤波与非线性风格，2×IIR抗混叠，独立原声/效果电平；旧三曲线保留 | 自研声音结构，未标定BOSS音色；高频混叠不能完全消除；[控制与结构](DIST_DYNAMICS_CN.md) |
| Dynamics／动态 | 自定义峰值压缩/限幅/门保留；新增十九个明确配方，含RMS/Peak、侧链高通、不同曲线/时间、音色EQ及电话带通 | 十九项是软件配方，不是十九套硬件算法；限幅无前瞻，非真峰值；[完整参数表](DIST_DYNAMICS_CN.md) |
| EQ／均衡器 | 低搁架＋两个独立中频峰值＋高搁架；四段 ±24 dB，两个中频各有频率/Q；图形控制点与数值同步 | 图示参考 48 kHz；频率/Q范围为软件单位，不冒充硬件旋钮刻度 |
| Octave／低八度 | 两路立体声移调，低一与低两八度，独立音量与原声混合 | 共用相位声码器窗口；有固定算法延迟 |
| Auto Pan／自动声像 | 正弦至更陡的周期曲线、相位0–180°、开启时重置相位；连续或阶梯，速度、拍同步和深度 | 波形尖锐度为连续映射，未经硬件0–100刻度标定；关闭重置时跟随共同拍相位 |
| Panning Delay／左右抽头延迟 | 共用普通 Delay 缓冲／滤波内核；左抽头为 Time × Ratio，右抽头为 Time，完整延迟交叉反馈 | 左右布局是可解释的自研实现；官方手册没有公布精确反馈拓扑 |
| Phaser／相位器 | 4/8/12 级一阶全通串联，手动中心＋速率/深度，反馈和混合；保留旧音色的6级 | 级数切换5ms交叉淡化；支持独立 STEP RATE；没有 BI-PHASE，中心刻度未经实机标定 |
| Flanger／镶边 | 短延迟调制、手动中心、反馈、左右相位差 | 支持独立 STEP RATE；没有通过零点的负延迟，中心改变的是延迟尺度，未经实机标定 |
| Sustainer／延音压缩 | 与 Dynamics 共用核心，默认更低阈值、较高比率和补偿增益；固定120Hz/6kHz低高音架，各±20dB | 音架在压缩后；默认0dB精确旁路。它会抬升录入噪声，不生成无限音 |
| Manual Pan／手动声像 | 左右声道平衡，中央保持原立体声，极端位置衰减另一侧 | 不等于把完整立体声折叠为一个声像点 |
| Stereo Enhance／立体声扩展 | 可选中声道短全通去相关生成侧声道；保留M/S宽度；侧声道低／高切0=FLAT，20Hz～12.5kHz | 生成侧声道固定200Hz四阶低切保护低音，M±S合并保留原mid且不增加主路径延迟；旧JSON默认不开启新增拓宽，不声称硬件等效 |
| Tremolo／振幅颤音 | 连续尖锐度的幅度曲线，速度、拍同步、深度；可选相位重置与阶梯 | 阶梯和相位属于软件扩展；不是重复触发 AHDSR |
| Vibrato／音高颤音 | 可变短延迟产生音高摆动，深度与速度 | 移动延迟会产生短延迟和边带，不是固定半音移调 |
| Step Slicer／步进切片 | 1～16 步音量柱、整周期拍同步、1–100%门宽；可选前级压缩，独立阈值与补偿增益 | 压缩采用4:1、2ms攻击/60ms释放的自研映射；门宽和压缩开关短平滑，是控制序列而非 MIDI 乐句 |
| Freeze／冻结延音 | 捕获约 90 ms 纹理，互补重叠窗持续播放；渐入、渐出、衰减和持续电平 | 是颗粒延音，不是频谱冻结；与按拍细分的 Roll 区别明确 |
| Chorus／合唱 | 立体声调制延迟，以相位差和混合产生增厚；湿声低切/高切均支持0=FLAT | 只过滤湿声；切频开关短平滑，具体延迟调制拓扑未经实机比对 |

Phaser、Flanger、Auto Pan 和 Tremolo 共用相位取样保持：关闭阶梯时保留原连续相位；启用后按独立 Hz 或拍间隔采样一次，并保持到下一格。拍时钟已经过 PDC 来源对齐，不再额外偏移。Auto Pan/Tremolo 的重置选项开启时，以该效果启用为同步相位起点；关闭则在共同拍相位上加相位偏移。旧JSON新增参数全为中性值；仅新建AutoPan默认开启相位重置。Sustainer的双音架系数按短平滑逐步更新，0dB时直接旁路；StepSlicer压缩默认关闭、门宽默认100%，不会改变旧预设声音。

### 音高效果的延迟

移调使用约 40 ms 量级的 FFT 窗口，取不小于目标的二次幂。在 **48 kHz 下是 2048 帧窗口，统一稳态与 unity 路径延迟为 2047 帧，约 42.65 ms**；44.1 kHz 下约 46.42 ms。展开编辑器按当前引擎采样率显示帧数与毫秒。开启 PDC 后，已配置的音高槽即使关闭开关或设为 0 半音，也保留相同窗口延迟；这样演奏时开关效果不会改变录音时间轴。关闭 PDC 时，固定 0 半音、无控制序列且无共振峰偏移的 Transpose 才使用原样直通。

窗口按采样率缩放：16 kHz 为 1024 帧（延迟约 63.94 ms），8 kHz 为 512 帧（约 63.88 ms）；低采样率并不保证音高处理延迟更低。

Electric 的清辅音、Harmonist 的原声以及音高效果内部的干湿声按同一窗口对齐。它们不因为音高比率接近 1 而忽然切到零延迟。各插槽的 FFT 运算时刻错开，但用零填充的初始窗口保持相同音频延迟；不能把“错开计算”变成“轨道错开播放”。

**0.4 提供项目级 PDC。** 先累计各串行分支的算法窗口，并对齐 Input Vocoder 的调制／载波、前级之后才加入的 OSC、五轨、输入监听与节拍器。混音延迟记为 M，Input FX 延迟记为 Li。较快分支延后到共同的 M；Delay、Reverb 等刻意的艺术延迟不被抵消。后级门控、滤波扫频、移调序列等读取到达该级音频的历史整数时钟，Track Filter 的循环游标也一起延后。手动参数按实际收到的时刻生效，不把所有人工操作重复延迟。

新工程默认开启PDC；旧JSON缺失时保持关闭。回环校准H是独立的设备测量，不包含M或Li。0.4.2起，「现场输入」录音分别写入两类来源：外部信号按H+Li+M归位，钢琴卷帘OSC贡献按Li归位；不再把已准拍的内部音频一起前移。选择「内部音源」仍让整路输入只按Li归位。分离使用正常输入处理W与持续运行的无生成器参考X之差G=W−X，共用非线性的交互也归G；不宣称它能还原任意混音的独立原始声部。监听仍使用W，不受H改变。量化仍到下一可调度边界，不会倒退改写已播放输出。

录音／叠录开始时固定当前录制段的偏移。会改变 Li 或 M 的 bank／类型／路由结构变更延后到所有录音及补偿尾部结束；推子、兼容的参数和 FX 开关仍可实时操作。界面显示等待状态，回放分别保存请求和实际应用的采样边界。回放渲染器 5 使用这些规则，旧渲染器继续无 PDC 时钟语义。PDC 只能对齐不同路径，无法消除实时监听的因果延迟；减少串联音高效果仍是降低监听等待的办法。

### 共振峰保持与偏移

Transpose、Electric、Harmonist、Octave 可选共振峰保持和 ±12 半音的谱包络偏移。新建 Electric／Harmonist 默认开启；旧 JSON 缺失字段时关闭，保留原音色。该开关不增加窗口长度。

实现采用源／滤波器分离思路：从当前频谱估计平滑包络，将移调后的包络去除，再按原位置或指定偏移重新着色。每两次音频 FFT 更新一次独立 512 点对数谱模型，执行三轮有界 true-envelope 投影；基频提示约束 lifter 阶数。校正最多 ±36 dB，并有帧能量保护；这不是无限迭代的原论文实现。少于三个明显谐波的稀疏信号回退到普通移调，避免把纯音当成人声声道。极弱声道不被放大成噪声。

合成元音测试验证了保持谱峰位置、偏移不改谐波频率、立体声反相与独立声道、8～192 kHz 有限值和无分配。真实元音、呼吸音、快速辅音与多人混合的听感仍需试听；大音程和复杂和弦会出现模型误差，瞬态仍受相位声码器限制，不能称为 BOSS 或 Serum 的等效算法。

## 既有效果完善

- **Filter**：保留 LPF/BPF/HPF 与自研 Notch，改为 TPT 状态变量结构，避免直接型系数突变时状态含义改变；截止频率仍按对数平滑。驱动增益归一化只在参数改变时计算。静态响应图与实际音频以多频点比较，高 Q、快速扫频在 8～192 kHz 下做有限性与无分配检查。共享内核也用于 OSC 内部滤波。独立 Input/Track Filter 另提供速率、深度和阶梯采样速率：Hz 或拍同步；深度按 ±4 个八度乘以百分比映射，属于公开控制语义的自研实现。自由Hz在演奏开始前也运行；拍同步跟随PDC校正后的来源时钟，停止则回到基础截止。Track原步进包络先执行，扫频再乘到其截止频率上；OSC内部仍使用自己的双LFO。默认Depth=0逐样本保持旧行为。
- **Vocoder**：现在支持两类机架。分析包络仍逐采样跟踪，谱包络整形、共振峰插值和倾斜每 16 帧计算并插值，减少大量逐采样指数运算。Track Vocoder 用当前轨的声音作调制信号，载波可来自实时输入或每帧的 FX 前轨道快照，避免依赖轨道处理顺序或产生瞬时反馈。Input Vocoder 保留原有载波通道／轨道语义。
- **Delay**：Input 与 Track 共用同一个内核，Panning Delay 在其上增加抽头布局。支持直接／效果电平、0=FLAT 高低切、1～16 次反馈或手动 0～100% 系数；“次数”映射为指定次数后衰减至 −60 dB，不冒充未公开的硬件反馈曲线。时间保存为浮点毫秒，直接输入精度 0.01 ms、键盘每次 1 ms，旧整数 JSON 兼容。100% 经过有限斜坡精确到 1，不暗中截成 .99；分数延迟在此端点使用一阶全通反馈，湿声抽头仍为线性插值。全通分数段限制在 0.5～1.5 samples，切换基址时从历史重建短状态，避免靠近零分数时的长高频振铃。95%↔100% 过渡短平滑。固定时间、无切频且未触及保护上限时可保持能量；切频、持续输入、饱和和时间调制仍会改变声音与能量，不能承诺所有移动操作无损。缓冲上限仍为 2 秒；同步音符超过上限时界面提示实际截到 2000 ms。测试覆盖 1/1.01/1.37 ms、整数边界、大跳变、重置和 8～192 kHz 无分配。
- **Roll**：补齐 Input 路由，两类机架共用配置、参数编辑与 DSP。关闭时仍捕获最近前级声音；Serial 严格按槽位，Legacy 明确最后处理。保留 Roll1 的反馈释放与 Roll2 的有限／无限重复；完整周期与细分语义不变。缓存循环段衰减，避免每采样重复计算幂函数，反馈在段内修改仍立即生效。清轨、类型／bank 切换不泄漏原冻结音频，修改Base cycle重新捕获；只切Step细分时重用同一冻结基础窗口，按新长度映射播放相位，不录入新声音，并以短淡化衔接。冷启动必须先集齐完整Base cycle，才能来回切换所有细分。回到干声采用平滑过渡；新增1 ms/1⁄16短片段、实时反馈修改、Input Roll 旁路捕获／重新捕获、bank/type 清理、无实时分配和工程／音色预设往返回归。
- **Reverb**：两类机架和主输出均使用扩散＋反馈延迟网络。缓冲清空改为有效长度标记，不在实时线程遍历大块音频；频率／RT60／预延迟的既有测试保持。机架 Reverb 与主混响共享 DSP，不宣称是 BOSS 原厂混响拓扑。

### OSC BOT 公开控制的补齐范围

现有OSC增加RECT（去直流的25%脉冲）、Detune Saw（±7音分的两个独立PolyBLEP锯齿）与Vintage Saw（高次谐波按`1/n^1.35`衰减的暖化锯齿，使用抗混叠分层波表）。这些模式有不同的实际频谱；它们是软件定义，不宣称来自BOSS波形数据。输入包络灵敏度通过实时输入的峰值包络控制OSC音量，保留AHDSR及音符门控；−50～50映射为±24dB增益，0以约−12dBFS峰值为满幅参考，并采用约5ms平滑。官方MOD SENS没有公开目标曲线，此映射明确属于本软件。

独立原声电平与OSC电平覆盖干湿混合需求；A→D逐槽混合，Legacy并行OSC仅将各原声系数乘积作用于原始输入，不互相削弱湿声。旧JSON默认原声100%、输入跟随关闭。ATTACK仍用明确毫秒的AHDSR；NOTE由乐句/独立试听承担，不恢复停止时的固定常鸣。TONE由现有内部滤波提供音色调整，原机刻度映射与波形听感仍未做实机标定。

## 主输出

音频／校准页包含主压缩和主混响开关，以及独立的完整编辑窗口。处理顺序为五轨推子后的和声＋打开 Input Thru 时的处理后输入 → 主压缩 → 主混响 → 输出保护。默认均关闭。

主效果改变最终听到的混音以及回放导出，**不写入各条循环轨道**。节拍器属于仅监听分支，在主输出之后加入；不会经主混响产生尾音或混入录音。

| Electric | 1345 ms | 1.506 ms | 1.692 ms | 2.018 ms |
| Octave（每实例两路移调） | 1862 ms | 2.179 ms | 2.409 ms | 3.590 ms |
| Dynamics | 150 ms | 0.148 ms | 0.264 ms | 0.408 ms |
| Reverb | 243 ms | 0.245 ms | 0.399 ms | 0.910 ms |

固定插槽相位错开 FFT 后，Transpose 的 p95 从集中处理时约 4.57 ms 降至约 1.18 ms；初始零填充保证不因此改变各槽音频延迟。**20 个 Octave 的峰值仍超过 128 帧预算**，并且基准未加满 OSC、录音页与设备驱动工作。高负载时应从 256／512 帧开始，或减少同时启用的音高实例；不能用平均 CPU 或一次 p99 推断声卡必然不会丢帧。真实声卡、蓝牙链路、演奏听感和 BOSS 对比仍需要设备验收。

0.4 另运行整引擎压力夹具：Input 为 1 ms／100% Delay→Transpose→1.01 ms／100% Panning Delay→EQ；五轨各运行 Transpose（共振峰开启）→Panning Delay→Electric（共振峰开启）→Reverb，同时叠录并请求延迟改变的 bank 切换。48 kHz、128 帧、3 秒音频的四次 release 运行，CPU 总耗时 **1054～1226 ms**，p95 **1.146～1.383 ms**，p99 **1.225～2.082 ms**，最大块 **1.528～4.193 ms**；全部有限值、逐次相同校验和，渲染及待应用配置交换 **0 次分配／释放**。偶发最大块超过 2.667 ms，仍不能保证 128 帧设备无欠载。相同夹具改为 **256 帧**时，3.0027 秒音频 CPU 1122 ms，p95 **2.333 ms**、p99 **2.531 ms**、最大 **3.114 ms**，低于 5.333 ms 理论预算；高负载建议先用 256／512 帧。此夹具不是全程启用所有可能模块，也不是声卡实测。

当前为了不在音频回调分配，各空槽和未激活 bank 也预备全部状态。**0.4 Windows release** 单个空 RenderCore 实测私有内存约 **280 MiB @ 48 kHz、1093 MiB @ 192 kHz**，初始化约 **77／327 ms**，包含 Input Roll、PDC 时钟／对齐缓冲和共振峰状态，不含后续录入的音频页。直播引擎与回放／跳转引擎可同时存在，内存会相加。FFT 计划已按窗口大小跨实例共享；后续宜改为控制线程按实际配置准备处理器状态，以进一步减少空槽占用。

## 公开算法参考

- [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)：四段均衡的双二阶系数与响应。
- [Julius O. Smith：Allpass Filters](https://www.dsprelated.com/freebooks/pasp/Allpass_Filters.html)：Stereo Enhance使用的短全通结构依据；具体双路径、侧声道滤波与低音保护为本项目设计。
- [Vadim Zavalishin：The Art of VA Filter Design](https://www.native-instruments.com/fileadmin/ni_media/downloads/pdf/VAFilterDesign_2.1.0.pdf)：拓扑保持与状态变量滤波思路。
- [Cytomic：Linear Trapezoidal State Variable Filter](https://cytomic.com/files/dsp/SvfLinearTrapezoidalSin.pdf)：状态变量结构与可调系数的公开推导。
- [Faust misceffects](https://faustlibraries.grame.fr/libs/misceffects/) 和 [Julius O. Smith：Time-Varying Delay Effects](https://www.dsprelated.com/freebooks/pasp/Time_Varying_Delay_Effects.html)：调制延迟、变调与相关效果的公开结构。最终移调采用自研流式相位声码器；没有复制 BOSS、FL Studio 或 Serum 的未公开代码。
- [Julius O. Smith：First-Order Allpass Interpolation](https://www.dsprelated.com/freebooks/pasp/First_Order_Allpass_Interpolation.html)：100% 反馈的分数全通结构，以及避开零分数延迟所需的数值约束。
- [Röbel、Rodet：Efficient Spectral Envelope Estimation and Its Application to Pitch Shifting, DAFx 2005](https://www.dafx.de/paper-archive/2005/P_030.pdf)：true-envelope、子采样和谱包络去除／重建；本实现限定为三次投影并加入保护。
- [Lenarczyk：Real Time Pitch Shifting with Formant Structure Preservation Using the Phase Vocoder, Interspeech 2017](https://www.isca-archive.org/interspeech_2017/lenarczyk17_interspeech.pdf)：相位声码器中音高与声道包络分离的公开研究。
- YIN 检测原始文献：Alain de Cheveigné、Hideki Kawahara，*YIN, a fundamental frequency estimator for speech and music*，JASA 111(4), 2002。本实现将固定窗口的候选延迟计算分散到采样步，限制单次工作量。
