# RC505 RS 操作手册

本手册对应 2026-09 的桌面工作台版本。目标是逐步覆盖 RC‑505mkII 的使用场景，并提供适合电脑的编辑工具；目前不是硬件的等效替代品。已实现范围和差异见 [硬件对照](RC505_REFERENCE.md)。

## 1. 安装、运行与数据

需要 Rust 工具链和 Windows MSVC C++ 构建工具。在项目根目录运行：

```powershell
cargo run --release --bin rc505_rs
# 启动器：选择设备、延迟补偿和工程后打开主程序
cargo build --release --bins
.\target\release\rc505_launcher.exe
# 已配置 ASIO SDK/驱动环境时才使用
cargo run --release --features asio --bin rc505_rs
```

两个可执行目标必须用 `--bin` 明确选择。需要整理预设但不使用声卡时：

```powershell
cargo run --release --bin rc505_rs -- --offline
# 使用独立的数据目录（也适合测试或便携工作区）
cargo run --release --bin rc505_rs -- --offline --data-dir=E:\RC505-data
```

默认数据位置：

| 数据 | 位置 |
|---|---|
| 工程索引、工程 JSON | `%APPDATA%\rc505_rs\projects\` |
| 单槽 FX 预设 | `%APPDATA%\rc505_rs\presets\` |
| 启动器设备配置 | `%APPDATA%\rc505_rs\launcher_config.json` |

`--data-dir` 替换上表中的 `rc505_rs` 根目录。无 APPDATA 时使用当前目录下的回退路径。启动器与主程序共用视觉主题，用于演奏前选择声卡、补偿和工程；也可以直接运行主程序。启动器会向主程序传递 `--data-dir` 和 `--offline`。

**工程目前保存参数、音符序列、FX 配置/开关和音轨音量，不保存录制的 loop 音频。** 返回工程列表、切换工程或退出后，录音不会恢复。不要把“保存工程”理解为保存录音。

## 2. 第一次录制

1. 在首页点击已有工程，或输入新名字并点击 **Create and open**。
2. 展开演奏台左上方的 **Audio devices & latency**，选择输入和输出设备。检查右上方声卡状态；离线模式可以改参数，但不能录音。
3. 设置 BPM。音频引擎会寻找双方共同支持的 f32 格式，优先立体声、48 kHz，其次 44.1 kHz。当前要求输入/输出有相同的声道布局；尚不支持任意单声道输入映射到独立立体声输出。
4. 点击 Track 1 的 **Record [1]** 或按数字 `1`。第一条轨道启动全局时钟。
5. 演奏一个乐句，再次点击 **Finish** 或按 `1`，在下一拍结束录制并进入循环。延迟补偿会多采集一段尾部，再调整录音位置。
6. 循环播放时再次按 `1` 进入叠录；再次按下，在轨道循环边界结束叠录。
7. 用其他音轨继续叠加；点击 **Stop** 或按 `F1` 停止 Track 1；点击 **Play** 或按 `1` 恢复。

建议用耳机避免软件监听与扬声器形成反馈。若声卡已经开启直接监听，注意它与软件监听叠加可能形成延迟重影。延迟补偿是录放对齐量，不是设备缓冲区大小。

## 3. 演奏台

![演奏台](images/performance.png)

### 顶部传输栏

| 控件 | 作用 |
|---|---|
| BPM / Tap | 输入速度或反复点击 Tap 估计速度 |
| All start / stop / `Space` | 有轨道运行时停止；全部停止时恢复已有轨道 |
| Save / `Ctrl+S` | 保存工程参数，状态栏显示成功或错误 |
| Projects | 返回工程列表前选择保存、放弃或取消 |
| Legacy keys / `S` | 切换旧式键盘参数编辑模式 |

时钟运行期间 BPM 锁定。停止所有轨道并关闭 **Sequence preview** 后可以修改。已有录音不会跟随 BPM 做时间拉伸；更改后它的实际秒数不变。

首次录音中按 Stop，会先在下一拍完成录音再停止；等待结束叠录时按 Stop，会在既定结束点后停止。已经正常播放/叠录的轨道可直接停止，并取消尚未开始的叠录任务。时序仍以现有音频回调和系统时钟为基础，不应假定达到专业 DAW 的采样级精度。

### 五条音轨

| 状态 | 大按钮 | Stop | Clear |
|---|---|---|---|
| Empty | 开始录音 | 无操作 | 不可用 |
| Recording | 完成录音并循环 | 完成后停止 | 不可用 |
| Playing | 进入叠录 | 停止 | 清除本轨录音 |
| Overdub | 在 loop 边界完成叠录 | 停止叠录与播放 | 不可用 |
| Stopped | 恢复播放 | 无操作 | 清除本轨录音 |

点击轨道标题选中该轨；紫色边框表示 Track FX 开关操作的目标。音量推子作用在 Track FX 之后，只改变听到的回放音量，不改写原录音，也不降低 Vocoder 的载波信号。鼠标与键盘使用相同的分贝刻度：最低端静音，其余范围约 −60 到 0 dB；音频侧使用约 5 ms 平滑。

### 键盘推子的速度与组合操作

| 轨道 | 降低 | 提高 |
|---|---|---|
| 1 | Z | X |
| 2 | C | V |
| 3 | B | N |
| 4 | M | 逗号 `,` |
| 5 | 句号 `.` | 斜杠 `/` |

- 短按改变 **0.5 dB**。按住超过 **180 ms** 后连续变化，随后在 **450 ms** 内由最高速度的 1/4 加速到最高速度。
- 按住 **Shift**：短按 **0.1 dB**；长按为设定最高速度的 **1/8**，不加速。默认精细速度为 3 dB/s。
- 在 **Keyboard faders & shortcuts → Hold speed** 设置最高速度，范围 6–60 dB/s，默认24；随工程保存。长按默认约3秒可从0 dB降到静音，精细模式更适合缓慢淡入淡出。
- 松键立即停止控制；同一轨升降键一起按住保持当前音量。可同时按 `Z + V`，让轨1降低、轨2提高，其他轨也能独立操作。
- 速度根据经过的时间计算，不依赖系统按键重复频率；窗口卡顿时限制单帧变化量。切换窗口、进入展开编辑器、旧小屏模式或文本输入时暂停推子按键。
- 轨道/FX 开关只响应一次按下，持续按住不会反复开关。实际同时可用的键数仍受键盘硬件的按键冲突/多键识别能力限制。

窄窗口下，**Quick parameters & settings** 默认折叠以优先展示轨道。展开可进入与大窗口相同的快速参数区；较长内容可纵向滚动。

波形是每条轨道的有限采样概览，约 10 Hz 刷新，不是精确的峰值分析仪。竖线是逻辑播放位置；当前没有音频裁剪、导出或 Undo/Redo overdub。

## 4. 两层效果与两级编辑界面

每层包含 **4 个 bank × 4 个槽位**。Input FX 与 Track FX 独立选择活动 bank；只有该层当前活动 bank 参与处理。

- 点击槽位名称：在右上方快速面板编辑该槽。
- 点击 **On / Enabled**：启用效果。Input FX 是全局输入开关；Track FX 开关属于当前所选音轨。
- 在快速面板选择效果类型，拖动滑条或点击数值输入。
- 点击 **Expand editor**：进入完整工作区；点击 **Back to performance** 或 `Esc` 返回。
- Oscillator / MyDelay 也可直接点击 **Open piano roll**。
- 改效果类型会把这个槽的参数重置为新类型默认值；先保存单槽预设可保留旧设置。

编辑目标包含 bank 和槽位，展开后不会因其他 bank 被选中而误改另一个槽。若正在编辑的 bank 不活动，界面会提示并提供 **Activate this bank**。

完整工作区按模块提供 Sound、Piano roll、Amp envelope、Filter、Filter envelope 页。其他效果直接显示其全部现有参数。参数实时更新同一份配置，返回演奏台无需再点击 Apply。

## 5. 用钢琴卷帘写旋律

![钢琴卷帘](images/sequence.png)

示例：Input FX A 选择 **Oscillator** → Enabled → Open piano roll → Starter melody → Sound 页将 Threshold 设为 0、Level 设到合适音量 → Sequence preview。

**Sequence preview 只启动序列时钟，不自动开启效果或绕过阈值。** 想无输入试听 Oscillator，应开启该槽并设 Threshold=0；MyDelay 仍需输入声音来采样。关闭预览后，若没有录放轨道运行，时钟停止；效果仍遵循其固定音符/门限设置，因此 Threshold=0 的 Oscillator 仍可能持续发声，需关闭 Enabled 来静音。

| 操作 | 结果 |
|---|---|
| 左击空白网格 | 插入一个当前 Snap 长度的音符 |
| 左击音符 | 选中，显示起点 tick 和长度 |
| 拖动音符主体 | 按网格移动时间和音高 |
| 拖动音符右边缘 | 改变长度 |
| 右击音符 / 选中后 Delete | 删除该音符并保留休止时间 |
| Undo / Ctrl+Z；Redo / Ctrl+Y | 撤销/重做音符操作，最多保留 64 次撤销 |
| Copy pattern / Paste | 复制/替换整个 pattern；可在不同槽之间粘贴 |
| Duplicate | 把整个 pattern（包括休止）复制到右侧，长度翻倍 |
| −12 / −1 / +1 / +12 | 整段移调，单位半音 |
| Clear notes | 清空音符，保留 pattern 时长 |
| Starter melody | 用一小节 C 小调示例替换，支持撤销 |
| Bars | 调整 loop 长度；缩短会裁掉右侧音符，支持撤销 |
| View octave / Zoom | 调整可见音区与横向缩放；横向滚动查看长序列 |

这是**单声部**序列。插入重叠音会替换相应的时间区间，并保留原音符未重叠的前后部分。相同音高的相邻音符仍保留独立触发点。未被音符占用的区间是休止，允许前导/尾随休止。

- 一拍是四分音符，内部 12 ticks；4/4 显示下每小节 48 ticks。
- Snap 1/16 = 3 ticks；1/8 = 6；1/4 = 12；三连音网格 1/24 = 2、1/12 = 4。
- 最长 384 ticks = 32 拍 = 8 小节。音高 C0–B9。
- 超出当前两八度视图的音符不会消失，底部提示隐藏数量；调 View octave 查看。
- 撤销仅覆盖音符编辑，不覆盖声音参数或预设加载。切换目标槽、加载预设、重开工程会清空撤销历史。
- 旧小屏 Step 的 `1/4` 表示 **1/4 拍**，相当于新钢琴卷帘的 **1/16 音符**；旧文件的时间基准没有改变。

## 6. 现有效果参数

### Oscillator

| 参数 | 范围；默认 | 说明 |
|---|---|---|
| Waveform | Sin / Saw / Sqr / Tri；Sin | 波形；Saw/Square 使用 PolyBLEP 抑制混叠 |
| Level | 0–100；100 | 合成音输出量 |
| Threshold | 0–100；10 | 输入包络阈值，数值除以 100 对应归一化振幅；不是 dB |
| Note / Octave | N 或 C–B；C4 | 时钟不运行或序列为空时使用固定音符；N 是休止 |

输入包络使用峰值保持和约 30 ms 衰减，避免音频过零点造成开关抖动。音量包络与滤波包络分别调制振幅和 cutoff。多个 Oscillator 会归一化混合，再与输入叠加；这不是硬件 OSC BOT 的完整参数映射。

### AHDSR 包络

| 参数 | 范围；默认 |
|---|---|
| Attack | 0–2000 ms；0 |
| Hold | 0–5000 ms；0 |
| Decay | 0–10000 ms；1000 |
| Sustain | 0–100%；100 |
| Release | 编辑/运行 1–5000 ms；旧默认 0 在运行时按 1 ms 处理 |
| Start | 0–100%；0 |
| Tension A / D / R | 0–1000；100 |

Attack 从 Start 上升到 1；Hold 保持峰值；Decay 到 Sustain；松开门限后 Release 回到 0。Tension=100 为线性，指数为 `2^((value−100)/50)`；不要沿用历史文档中的“50 为线性”。

图形由同一 AHDSR 状态机模拟，展示一段含 300 ms sustain 的参考门限。竖线表示 note off，不是实时声卡波形。极短阶段在有限采样的预览中可能难以分辨。

### Filter

| 参数 | 范围；默认 | 说明 |
|---|---|---|
| Type | LPF / HPF / BPF / Notch；LPF | 低通、高通、带通、陷波 |
| Cutoff | 20–20000 Hz；1000 | 对数滑条 |
| Q (×0.1) | 1–100；7 | 对应实际 Q=0.1–10.0，默认 0.7 |
| Drive | 0–100%；0 | 混入归一化 tanh 饱和；0 为线性 |
| Mix | 0–100%；100 | 干湿线性混合 |

cutoff 和 Q 有约 20 ms 平滑。可拖动响应图：横向调整截止频率，纵向调整 Q。曲线使用实际 biquad 系数计算，但参考采样率固定为 48 kHz；包含干湿相位叠加，不包含非线性 Drive 或包络运动。

Oscillator / MyDelay 内部滤波包络把 cutoff 从 20 Hz 调制到所设上限。Track Filter 另外提供可视 step gate：Append step、Remove last，点击 step 方块开关整段门限；展开 Cutoff envelope 调整包络。时间基准跟随本轨播放位置。

### MyDelay（自定义效果）

Level 0–100（默认100），Threshold 0–100（默认35），附带音符序列、音量包络、滤波器和滤波包络。输入超过阈值后采集约 100 ms，再按音符对应周期循环，边缘加窗。它不是常规回声，也不是已确认的 RC‑505mkII 同名算法。

现在连续输入不会在每次过零时重启采样。它适合从人声或瞬态提取音色；无输入时无法凭空产生有用的采样音色。

### Reverb

| 参数 | 范围；默认 | 说明 |
|---|---|---|
| Size | 0–100；50 | 映射延迟线基本长度约20–120ms |
| Decay | 100–12000 ms；2500 | RT60 衰减时间 |
| PreDelay | 0–500 ms；20 | 预延迟，0直接进入扩散器 |
| Width | 0–100%；70 | 立体声宽度 |
| HighCut | 0–100%；30 | 高频阻尼量，并非 Hz |
| LowCut | 20–1000 Hz；120 | 低频清理 |
| Direct / Effect level | 0–100%；100 / 35 | 独立干声、湿声电平 |
| Density | 1–10；5 | 输入全通扩散量，1关闭扩散 |

采用输入全通扩散器和4线FDN。展开界面提供干湿电平、密度和阻尼。旧工程缺少新增字段时，按 Direct=100、Effect=35、Density=1 导入，保留旧固定混合比例和无扩散的行为。高切仍沿用阻尼百分比，没有伪装成硬件的Hz刻度；Size、Width及12秒上限属于软件实现。

### Vocoder

| 参数 | 范围；默认 |
|---|---|
| Carrier | Tr1–Tr5、Input L、Input R；Tr1 |
| Bands | 4–16；10 |
| Attack | 0–200 ms；6 |
| Release | 0–1000 ms；80 |
| Level / Mix | 0–100%；100 / 100 |
| Tone | −50到50；0，调节频谱倾斜 |
| Mod sensitivity | −50到50；0，映射为包络检测前±18 dB灵敏度 |
| Formant | −12到12半音；0，移动频谱包络，保留载波音高 |
| Sibilance | 0–100；20，增强高频分析带，不注入噪声 |
| Carrier thru | Off / On；Off，只对输入载波有效 |

先在一条轨道录制有谐波的合成器/人声等载波，再用输入调制它。载波太接近纯正弦时，口型塑形会很弱。当前载波来自 Track FX 后、音轨推子前；暂停的载波轨在全局时钟运行时可继续向 Vocoder 提供信号，不播放其干声。载波轨为空时没有对应湿声。

选择 Input L 时：将载波送入左通道、语音送入右通道；Input R 则相反。使用的是一个立体声输入设备，不是硬件的多组独立 MIC/INST 接口。Carrier thru 控制载波所在通道的干声是否参与 Mix；Mix=100时输出纯湿声。

滤波器组现在缓存系数，使用独立立体声合成通道；保留并调整此前“共振峰对比度增强”的思路，按整个频谱包络归一化，避免逐带削平。Formant、Bands、Release、Sibilance 是软件提供的扩展；Attack 仍使用毫秒而非硬件0–100刻度。没有实机 A/B 录音，不能把这些参数称为已经完成硬件声学标定。

### Track Delay

Time 1–2000 ms（320），Feedback 0–95%（35），HighDamp 200–20000 Hz（10000），Mix 0–100%（40）。立体声独立延迟线，分数延迟插值，时间/反馈/阻尼/混合约25ms平滑。Time mode 可以选毫秒、1/4、1/8、附点1/8、1/16、1/8三连音，按当前 BPM 计算时间。改变延迟时间时可能产生滑音。反馈保留软件百分比，未映射成硬件的重复次数刻度。

### Track Roll

| 参数 | 作用 |
|---|---|
| Mode | Roll 1：反馈衰减；Roll 2：重复次数 |
| Base cycle / Time | 毫秒1–1000，或与Delay相同的五种节拍值；默认1/4音符 |
| Step | Off、1/2、1/4、1/8、1/16；默认1/4 |
| Feedback | 1–100%；默认50，仅Roll1且Step=Off时生效 |
| Repeat | 1–100次；0代表无限，默认0；仅Roll2且Step=Off时生效 |
| Balance | 干湿0–100%；默认100 |

旁路时持续保留最近的立体声输入，开启时冻结其中一段，**包含此前 Track FX 的输出**。Step分割的是Base cycle；在120 BPM、Base=1/4音符、Step=1/4时，循环片段为125ms。Step=Off只是关闭细分，仍保留整个基础周期的重复效果，不等于旁路。

Roll1按每次循环衰减，Feedback=100无限保持；Roll2按指定次数播放后回到干声。细分开启时持续重复，忽略Feedback/Repeat。开关混合约5ms平滑，片段接缝有短交叉淡化。重新关闭/开启可重新捕获；片段长度改变时重新收集声音。新bank或没有足够历史时，先输出干声并等待收满一个片段。缓存最长2秒。

旧工程Step=2/4/8仍可载入，但从“整条loop分段叠加”改成单片段冻结后，听感有意改变。Roll1反馈曲线、重复边界和硬件的精确瞬态仍需实机标定。

## 7. 工程、预设与退出

- **Save / Ctrl+S** 保存工程整体参数，包括所有 bank 的定义、各轨开关和音量。
- 展开编辑器中的 **Save as new** 只保存当前 FX 槽的类型及参数；给新名字即可保存变体。支持字母、数字、中文、空格、`-`、`_`，名称最长100字节。不覆盖同名预设。
- **Load preset** 载入当前槽；Input/Track 两类不能混用。载入不会改变 BPM、设备、其他槽或该槽当前开关状态。
- 工程写入先写临时文件再替换；失败会留在当前界面并显示错误。损坏的工程 JSON 会报告打开失败。
- 退出项目或关闭窗口，出现 Save and exit / Discard / Cancel。保存失败不会继续退出。
- 最稳妥的备份方式是复制整个数据根目录。原始 loop 音频不在其中。

## 9. 排查问题

| 现象 | 检查 |
|---|---|
| 无声音 | 是否离线；声卡状态；活动 bank、Enabled、轨道 Level；Oscillator Threshold；载波是否为空 |
| 预览不播放旋律 | 当前槽是否 Oscillator/MyDelay、序列是否有音符、时钟是否运行；确认没有编辑非活动 bank |
| 停止预览仍有声音 | Preview 是时钟开关；Threshold=0 的固定音 Oscillator 仍发声，关闭效果即可 |
| 输入/输出无法开启 | 选择共同支持 f32、相同声道布局的设备；检查采样率及其他独占程序 |
| 叠录错位 | 调延迟补偿，再录短瞬态检查；不要在录放时切换设备 |
| 声音失真 | 降低输入、Oscillator Level、反馈/Drive 与音轨音量；总线仍有硬限幅，尚无母线 limiter |
| 工程打开后无录音 | 当前工程只存参数；音频持久化尚未实现 |
| 窗口较小看不全 | 演奏台/编辑器支持纵向滚动，钢琴卷帘支持横向滚动；最小窗口960×640 |

目前仍存在音频回调中的锁和动态内存、不同设备时钟漂移及延迟补偿误差。请参阅 [规划](../AGENTS/PLAN.md) 与 [验证记录](VALIDATION.md)。
