# RC505 RS 图标

图标由图像生成工具辅助制作，以五轨循环、合成器波形和音频软件的识别度为设计元素，采用深蓝、薄荷绿与蓝紫配色，未直接使用其他品牌的标志。

- 原始透明 PNG：`assets/rc505-rs-icon-v1.png`，1254×1254，保留 alpha 通道。
- 程序与窗口 PNG：`assets/rc505-rs-icon-v1-256.png`。
- Windows ICO：`assets/rc505-rs-icon-v1.ico`，包含 16、24、32、48、64、128、256 像素层。

ICO 和 256px PNG 由同一原图缩放、转换得到。主程序、音频启动器、安装器和快捷方式使用同一图标；Windows 可执行文件嵌入图标及版本信息。
