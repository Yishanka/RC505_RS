# 0.2.7：试听、节拍器与连续历史

- 回环校准改为先静音、再接线测量、拔线确认后恢复；失败、切换设备和重启均保持保护。界面说明软件就绪条件与必要线路接口。
- 钢琴卷帘明确固定循环长度，越界编辑不自动延长；修正中英文提示，移除停止状态固定音符/八度控制。
- F9 不再受普通参数焦点或空转时钟阻挡，不能录制时显示原因。顶部 F10 回放库，点击播放自动重算并进入播放器。
- 节拍器启动正式时钟，独立音量及四拍重音；FX 试听使用私有时钟，不必开始演出。不支持序列的 FX 不显示试听。二者均只进入监听。
- 背景显示最终监听声音的轻量峰值音柱，可关闭；整理顶部操作行及轨道停止/撤销/重做按钮。
- 每轨最多 8 步录音、叠录、清空历史，按音频页预算限制；Alt+1–5 撤销、Ctrl+Alt+1–5 重做。钢琴卷帘保留连续 64 步 Ctrl+Z/Y。音频快照保存轨道历史并复用共享 WAV。
- 快照升级为 3 并读取 2；回放 renderer 3 同时保留 renderer 2 的旧声音及撤销语义。未完成物理回环、设备听感和实机 A/B 验证。

- 修复展开编辑器沿用小面板控件 ID，导致方向键、Tab 移动到无效焦点并触发 Windows AccessKit 崩溃的问题。导航只选择当前界面实际存在的控件，并清理弹窗/页面切换后的旧焦点。
- 快捷键收敛为 F6 顶部、F7 左面板、F8 效果面板，移除 A/D 重复入口。F8 不再关闭展开界面；Esc 返回，Ctrl+Tab / Ctrl+Shift+Tab 切换完整编辑器页面。保存提示区分返回工程与关闭软件。
- 恢复录制/叠录时的四拍亮点和边框脉冲，跟随音频采样时钟。
- 钢琴卷帘支持完整 C0–B9 音域、双向滚动条、滚轮/Shift+滚轮及中键平移；键名和时间标尺固定，滚动后的绘制、移动、调整长度和撤销保留正确坐标。
- 增加启用无障碍树的完整 UI 导航回归、滚动编辑测试，以及无控制台环境的本地崩溃日志。

# 0.2.5：跟随系统输出设备

- 修复旧设备名锁定输出：默认及旧版配置迁移为「跟随系统输出设备」，保留明确的手动固定模式。
- 后台检测 Windows 默认输出端点变化，运行中自动切换；使用端点 ID，不依赖耳机品牌或名称。
- 输出切换移交同一渲染器，保留循环、录音状态、播放位置、撤销和效果历史；输出采样率变化在输出端转换。
- 无设备时保留状态并自动重试；界面显示实际输出，新增 `--audio-info` 诊断命令。切换设备会使旧回环测量失效。

# RC505 RS 0.2

0.2.3补充：修正Windows输入层对Shift+数字和标点的字符转换，确保组合停止键及第4/5轨速度键按实际按键工作；只在当前程序的演奏焦点读取这些按键，编辑文字和失焦时隔离。主分支CI也执行安装器验证，发布前更早发现打包问题。

更新助手固定使用Windows PowerShell及其系统模块，避免从PowerShell 7启动时继承不兼容模块路径而无法校验文件。

新增原创循环/五轨波形图标，统一用于程序、启动器、窗口和安装器；[设计与生成提示词](ICON_DESIGN.md)。

0.2.2修复：安装器的旧数据导入改为显式可选开关；修正不导入时新安装/升级被空路径校验中止的问题。发布前自动测试无导入安装、再次安装及数据保留。0.2.1安装包已退出稳定更新通道，推荐直接使用0.2.2。

成功更新后只保留一份 `RC505-RS-setup.exe`，清理旧版本安装缓存；安装失败时保留旧包以便重试。

Windows x64构建静态链接C运行库，减少对另装VC++运行库的依赖。

0.2.1补充：Updates页可直接打开数据/下载目录，新增 `--installation-info` 输出实际程序版本和路径，方便核对安装、迁移与更新结果。配置创建、预设与离线回放不再枚举声卡，避免无音频设备的Windows环境访问驱动。音频renderer保持版本2，与0.2.0回放兼容。

这版把工程存档、演奏调度和回放统一到采样时钟，并提供可安装、可更新的 Windows 发布包。没有新增 FX 类型。

- 启动进入居中的工程选择页；固定上方面板、放大字体、内置帮助，移除旧 S 模式。F6 / A-F7 / D-F8 分别聚焦顶部、左侧和右侧控件。
- 推子速度按轨保存；Shift + 对应推子键调速度。新增直接选轨、组合停止、临时 FX、直接选 bank、按住清轨等操作。
- 保存 config 或 config + 音频 snapshot；32-bit float WAV、版本化清单、SHA-256 校验、后台保存、索引恢复和回收站。
- 回放存储输入与采样编号操作，重新运行相同 DSP 导出 WAV；独立播放器、导入原工程或新工程。
- 音频回调改为单一 DSP 所有者、有界队列和后台回收；分页音频支持保存时继续演奏及一层 Overdub Undo/Redo。
- One Shot、Reverse、立即/loop结束/淡出停止、固定录音长度、Off/Beat/Measure/Loop 量化。
- 输入时钟漂移适配、运行统计和三次回环校准建议；校准结果以采样数保存。
- Input FX 可保留旧分组顺序或选择 A→D；Delay 独立 Direct/Effect 与反馈低切，Reverb 高切改为 Hz 并迁移旧阻尼值。滤波器和混响控制系数缓存降低重复计算。
- Windows 安装器分别选择程序、数据和下载目录；默认数据放程序的 `data` 子目录。支持复制旧数据、软件内检查更新、保存后安装更新。

回放从已停止的五轨开始，重置 FX 尾音；结束前需完成录音/叠录。单轨最多五分钟，单次回放最多三十分钟。回放绑定 renderer 版本，不能承诺跨未来算法版本逐位兼容。

自动化验证覆盖实际渲染路径零分配、采样边界、回放逐位重现、存档损坏检测、采样率转换及核心 DSP。未进行 RC‑505mkII 实机 A/B、物理回环校准和声卡长期压力测试；驱动与键盘多键能力仍需用户设备验收。
