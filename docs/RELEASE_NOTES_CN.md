**边界：**PDC会增加等待时间，不能消除监听和设备延迟；量化操作仍按下一可调度引擎拍点执行。内外音源混合后无法分别补偿，建议分轮录入。重效果工程建议256/512帧；离线128帧压力曾超过预算。完整场景编排、部分BOSS专有子型号与实机A/B仍在后续规划，详见[用户手册](USER_GUIDE_CN.md)、[算法与测量](FX_IMPLEMENTATION_CN.md)和[规划](PLAN.md)。

**测试版迁移说明：**新音色/包络算法会改变旧工程和旧回放听感。旧 MyDelay 未保存的捕获缓存无法从 JSON 恢复，迁移后需重新捕获或导入素材；旧回放会有专门提示，要求保留原声音时请用旧版先导出音频。已经录入并保存的轨道音频不被迁移为别的声音。
