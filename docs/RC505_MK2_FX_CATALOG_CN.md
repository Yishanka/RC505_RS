# RC‑505mkII 内置效果完整清单与中文速记

核对日期：2026-10-03。这里的“插件”指机器内置 FX 类型，不是另外安装的 VST。名称和可用位置按官方手册核对；中文栏是便于选型的简短说明，不是原文逐句翻译或对内部 DSP 的断言。

## 数量与版本怎么数

官网标称 **49 种 Input FX、53 种 Track FX**，每个区最多同时使用 4 个效果。[官方规格](https://www.boss.info/us/products/rc-505mk2/)

rev.04 手册将 **TAPE ECHO1/2**、**ROLL1/2** 分别展开为两张参数表。下面将每一组归为一个效果家族，列出 **49 个共用家族＋4 个 Track 专用家族**；两组的 1/2 版本都包含在表中。若把它们拆成独立行，就会有 51＋4 行，不能把这种整理方式擅自改称新的“官方 55 种”规格。MODE 子选项、失真子类型、音箱型号也不重复计数。官方更新记录确认旧 RC 算法后来被补进若干效果；菜单细节需结合固件版本理解。[版本说明](https://www.boss.info/global/support/by_product/rc-505mk2/updates_drivers/5c6ad538-d4c8-4187-8a4b-384b7117061c/)

## 不要遗漏，也不要混算

- **主效果**还有压缩、混响；输入/输出混音器还有相应的电平、EQ 等处理。它们不计入上面 49/53 的插入效果清单。[产品与混音说明](https://www.boss.info/us/products/rc-505mk2/)
- PREAMP 的音箱型号、DIST 的失真风格、DYNAMICS 的动态风格是各效果内部选项；需实现时再展开参数，不在这里重复算成几十个插件。
- 当前软件的 **OSC 采样波形（旧 MyDelay）**、钢琴卷帘及独立试听是自研功能，不能加进“官方效果列表”。
- “音高相关”不等于“支持钢琴卷帘”：移调、弯音、低八度通常操纵已有音频；可演奏音源才需要 Note On/Off。具体架构建议见[设计讨论](DESIGN_SYNTH_SEQUENCER_CN.md)。
> 压缩、混响优先做

## 批注中几个名字的直观解释

- **SYNTH**：把收到的声音加工成合成器质感，手册给出滤波频率、共振、衰减与干湿平衡。它不是“再开一个按钢琴卷帘发声的 OSC”。手册没有公开内部跟踪或重合成算法，本轮只解释，不另加类型。
- **AUTO RIFF**：你弹/唱一个音，机器按选好的模式自动跑一段短乐句。官方提供 30 种 Phrase，以及速度、保持、循环和调性；需要分析输入音高，明确要求单声部。它与“自己在卷帘写旋律”不同。本轮只解释。
- **PITCH BEND**：把已有声音连续滑向目标音高，例如从原音滑高一整个八度。PITCH 选择范围，BEND 决定滑到了范围的哪里。Transpose 更像固定“整体高几半音”。本轮不另做 Pitch Delay。
- **ELECTRIC**：如果你说的“电音”指修音后音高跳格、机械感的人声，那就是这一类；它不是泛指电子舞曲。官方还包含 Formant、Speed、Stability、Scale 等参数。软件新增版本优先实现音高阶梯与调式，未实现的共振峰保留不能算已经复刻。
- **OSC BOT 与我们的 OSC**：用途有交集，但不能严谨地称完全超集。我们的复音、采样与曲线调制是软件扩展；BOSS 的触发、参数映射和音色仍需对照。按用户决定合并 MyDelay 为 OSC 的采样音源，不另外加一个重复的 OSC BOT 类型。

依据：[官方参数表，第 35–38 页](https://static.roland.com/assets/media/pdf/RC-505mk2_Parameter_eng04_W.pdf#page=35)。以上只解释官方控制含义；软件具体算法以本轮实现和验证记录为准。

## 本轮实现与仍存在的缺口

原建议已部分落实；具体算法、参数范围、延迟和验证见 [FX 实现说明](FX_IMPLEMENTATION_CN.md)。以下保留后续评估方向：

1. **已接通** Transpose、Octave、Electric 和 Harmonist；下一步是共振峰保持、瞬态质量和跨轨 PDC。Pitch Bend 仍只解释，没有独立类型。
2. **已接通** Reverb/Vocoder 的 Track 路由；Track Vocoder 使用 FX 前载波快照，具体语义与 Input Vocoder 区分清楚。
3. **已接通** Panning Delay，仍需 BOSS 实机确认抽头布局、反馈次数曲线与切频位置。
4. **已接通** Step Slicer、Tremolo 等共同采样时钟调制；硬件的额外波形、步长与压缩子参数尚未全部覆盖。
5. **仍未实现** Granular Delay、MIDI 自动和声以及表中未批注开发的其他家族。已实现家族也不等于硬件所有参数、子型号和 Mode 1/2 已复刻。
