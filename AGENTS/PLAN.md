## P0尚需真实设备验收

- [ ] 用户声卡不同buffer、长时五轨录叠/高FX负载、设备拔插、驱动超时；记录回调分位数和系统调度抖动。自动测试不能代替声卡压力测试。
- [ ] 物理回环接线测得补偿并听录音接缝；检查不同声卡时钟适配在真实漂移下的稳定性。
- [ ] 用户键盘多键、输入法、Fn、失焦和演奏手感测试；根据实际习惯迭代默认键位。
- [ ] 异常断电/磁盘满/被安全软件阻止等系统级故障注入。当前已有原子提交和校验，但不声明所有文件系统均具备断电原子性。

## P1硬件测量与后续算法标定

- [ ] 收集RC‑505mkII与软件的同输入、同参数成对音频。重点：Vocoder元音/齿音、载波串音，Roll取样边界/反馈次数，Delay时间切换，Reverb RT60与声场。
- [ ] 基于测量确认硬件控制曲线与软件曲线的映射。当前参数名称/范围相近不作为音色等效证据。
- [ ] OSC BOT完整控制映射；当前Oscillator仍是带序列/双包络的软件合成器，MyDelay仍是软件自定义效果，不改名伪装成硬件算法。
- [ ] 可视处理图扩展到并行分支、多输入/输出和显式通道映射。目前已有Legacy/Serial两种实际可运行输入路由及信号说明。

以上需要实机或外部测量材料，不能靠修改代码直接完成验收。

## 后续产品能力

- 可编辑快捷键、MIDI/脚踏学习、场景与参数自动化。
- Loop裁剪、波形完整峰值缓存、更多撤销层数、通用音频文件导入。
- 回放中途开始时完整DSP状态序列化、时间轴拖动、跨renderer版本兼容；目前以停止时重置作为明确边界。
- 键盘卷帘多选/框选/试听和力度（需要DSP支持），更细的时间网格。
- 新FX仅在现有功能经设备验收后按真实需求选择，不提前添加空壳类型。
