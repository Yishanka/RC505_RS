# 音频会话、演奏交互与安装发布升级

用户在上一轮工作台基础上要求修正工程选择/焦点/字体/推子速度，补音频持久化、操作回放、时钟与实时治理、五轨模式，并实际完成E盘安装和后续更新通路。本次没有新增FX类型。

主要变化：

- 移除旧MainScreen、画布小屏、wall-clock Track/Metronome调度。UI按固定面板组织，F6/F7/F8及A/D明确焦点；逐轨Shift速度、组合停止/选轨、临时FX和防误触清空。
- RenderCore同时用于现场与回放；frame/sequence决定操作次序。输出回调独占DSP，输入SPSC、有界命令、参数交换、异步回收；分页共享loop实现snapshot和Undo。
- 保存配置与保存音频分开；WAV、版本化清单、SHA-256、原子指针提交；索引恢复、回收站、唯一身份和编辑器目录锁。
- 回放保存clean初始状态、原始输入与操作。起点必须停止、终点需完成录音/叠录；原版本算法重算，独立播放器及受限目标导入。
- Input FX可保留分组或按槽；Delay独立电平/低切，Reverb高切Hz迁移，Filter/Reverb控制系数缓存。仍区分公开控制语义和未获得实机证据的听感。
- 安装器分开配置程序/数据/下载目录，数据默认程序旁data；复制校验迁移、软件内更新和tag触发的Release工作流。FFmpeg非必需。

关键回归：五轨重FX含COW/Undo/Clear的渲染区间分配/释放为0；输入/操作回放逐位重现；采样量化长时无累积舍入；WAV损坏拒绝加载；Windows可写句柄刷盘修复；可视化由真实egui截图验证。

验收结果集中维护在[VALIDATION](../../docs/VALIDATION.md)。完整参数与操作见[手册](../../docs/USER_GUIDE_CN.md)，发布流程见[安装文档](../../docs/INSTALL_UPDATE_CN.md)，硬件尚需验收的项目见[PLAN](../PLAN.md)。未提供RC‑505mkII实机和回环接线，不能关闭硬件声学标定或声卡压力测试。
